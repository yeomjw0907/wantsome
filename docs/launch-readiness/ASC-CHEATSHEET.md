### 2단계 이후: 각 카테고리별 sub-question

체크한 각 항목마다 ASC가 **수집 목적·연결 여부·추적 여부**를 묻습니다. 통일된 답:

#### Sub-question A: 수집 목적
✅ 체크할 것:
- **앱 기능** (App Functionality)

체크 안 함:
- 분석 (단, 충돌/성능/기타 진단 데이터만 분석도 함께 체크)
- 제품 개인화
- 앱 기능 외 사용자에게 적합한 광고
- 제3자 광고
- 개발자의 광고 또는 마케팅
- 기타 목적

> **예외**: 충돌 데이터·성능 데이터·기타 진단 데이터는 "앱 기능 + 분석" 둘 다 체크.

#### Sub-question B: 사용자 ID에 연결되어 있나요?
| 데이터 | 답 |
|---|---|
| 이름, 이메일, 전화번호, 사용자 ID, 사진/영상, 오디오, 구매기록, 기기 ID | **예 (연결됨)** |
| 충돌 데이터, 성능 데이터, 기타 진단 데이터 | **아니요 (연결 안 됨)** |

#### Sub-question C: 사용자 추적에 사용되나요?
**전부 "아니요"** (NSPrivacyTracking: false와 일치)

## 🔍 IAP 가격 KRW 티어 매핑

Apple은 KRW 티어가 정해져 있어요. 가이드 가격과 가장 가까운 티어:

| 코드 가격 | Apple KRW 티어 | 비고 |
|---:|---:|---|
| ₩6,600 | 티어 ₩6,600 또는 가까운 값 (₩6,500 또는 ₩7,000) | 정확히 매핑되는 게 없으면 가장 가까운 |
| ₩9,900 | 티어 ₩9,900 (Tier 7 부근) |  |
| ₩27,500 | 티어 ₩27,500 또는 ₩28,000 |  |
| ₩46,200 | 티어 ₩46,000 또는 ₩47,000 |  |
| ₩85,800 | 티어 ₩86,000 |  |
| ₩143,000 | 티어 ₩143,000 |  |

> 정확한 가격을 직접 입력하면 Apple이 가장 가까운 KRW 티어로 자동 매핑합니다.
